# Știri MD — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Un site public care agregă știrile din presa din R. Moldova (RO), le deduplică pe subiect și afișează un rezumat sintetizat din toate sursele, într-un format curat, fără reclame.

**Architecture:** Două sub-proiecte sub `apps/stiri`, partajând aceeași bază D1 și același index Vectorize. `pipeline/` e un Cloudflare Worker (Cron Trigger → Queues) care descoperă articole din RSS, extrage textul, calculează embeddings (Workers AI `bge-m3`), grupează prin similaritate + confirmare LLM (Workers AI `llama-3.1-8b`), și scrie rezumatul sintetizat (Workers AI: `llama-3.1-8b` pentru single-sursă, `llama-3.3-70b` pentru multi-sursă). `site/` e o aplicație Astro pe Cloudflare Pages care citește din D1 și randează știrile. **Totul pe Cloudflare — fără chei/API externe.**

**Tech Stack:** Cloudflare Workers, Queues, Cron Triggers, D1 (SQLite), Vectorize, **Workers AI** (binding `AI`: `@cf/baai/bge-m3` embeddings 1024 dim, `@cf/meta/llama-3.1-8b-instruct-fp8-fast`, `@cf/meta/llama-3.3-70b-instruct-fp8-fast`); Astro (adaptor Cloudflare); TypeScript; Vitest.

```typescript
import type { FeedItem } from "../types";

function block(tag: string, xml: string): string[] {
  const re = new RegExp(`<${tag}[\\s>][\\s\\S]*?</${tag}>`, "gi");
  return xml.match(re) ?? [];
}

function tag(name: string, xml: string): string | null {
  const re = new RegExp(`<${name}[^>]*>([\\s\\S]*?)</${name}>`, "i");
  const m = xml.match(re);
  if (!m) return null;
  return decode(stripCdata(m[1])).trim() || null;
}

function stripCdata(s: string): string {
  return s.replace(/<!\[CDATA\[([\s\S]*?)\]\]>/g, "$1");
}

function stripHtml(s: string): string {
  return s.replace(/<[^>]+>/g, "").replace(/\s+/g, " ").trim();
}

function decode(s: string): string {
  return s
    .replace(/&amp;/g, "&").replace(/&lt;/g, "<").replace(/&gt;/g, ">")
    .replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&nbsp;/g, " ");
}

function toIso(raw: string | null): string | null {
  if (!raw) return null;
  const d = new Date(raw);
  return isNaN(d.getTime()) ? null : d.toISOString();
}

function atomLink(xml: string): string | null {
  const m = xml.match(/<link[^>]*href="([^"]+)"[^>]*\/?>/i);
  return m ? m[1] : null;
}

export function parseFeed(xml: string): FeedItem[] {
  const items = block("item", xml);
  const entries = items.length ? items : block("entry", xml);
  return entries
    .map((raw) => {
      const url = tag("link", raw) ?? atomLink(raw);
      const title = tag("title", raw);
      if (!url || !title) return null;
      const desc = tag("description", raw) ?? tag("summary", raw);
      return {
        url,
        title,
        author: tag("author", raw) ?? tag("dc:creator", raw),
        publishedAt: toIso(tag("pubDate", raw) ?? tag("published", raw) ?? tag("updated", raw)),
        excerpt: desc ? stripHtml(desc) : null,
      } as FeedItem;
    })
    .filter((x): x is FeedItem => x !== null);
}
```

(Într-un Worker se poate folosi și HTMLRewriter în streaming; aici păstrăm o funcție pură testabilă. Folosirea în producție extrage `<p>`-urile din HTML-ul deja descărcat.)

```typescript
function decode(s: string): string {
  return s
    .replace(/&amp;/g, "&").replace(/&lt;/g, "<").replace(/&gt;/g, ">")
    .replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&nbsp;/g, " ");
}

export function extractText(html: string): string {
  const cleaned = html
    .replace(/<script[\s\S]*?<\/script>/gi, "")
    .replace(/<style[\s\S]*?<\/style>/gi, "");
  const nav = /<(nav|header|footer|aside)[\s\S]*?<\/\1>/gi;
  const body = cleaned.replace(nav, "");
  const paras = [...body.matchAll(/<p[^>]*>([\s\S]*?)<\/p>/gi)]
    .map((m) => decode(m[1].replace(/<[^>]+>/g, "")).replace(/\s+/g, " ").trim())
    .filter((p) => p.length > 40);
  return paras.join("\n\n");
}
```

```typescript
export interface Thresholds { attach: number; confirm: number; }
export const DEFAULT_THRESHOLDS: Thresholds = { attach: 0.86, confirm: 0.72 };

export type ClusterDecision = "attach" | "confirm" | "new";

export function decideCluster(
  bestScore: number | null,
  t: Thresholds = DEFAULT_THRESHOLDS
): ClusterDecision {
  if (bestScore === null) return "new";
  if (bestScore >= t.attach) return "attach";
  if (bestScore >= t.confirm) return "confirm";
  return "new";
}
```

**Step 3: Implementare.** Formatarea respectă regula română: „de" pentru numere terminate în 00–19 din interval ≥20 (simplificat: n%100 între 0 și 19 și n≥20 ⇒ „de").

```typescript
export function importanceScore(
  sourceCount: number,
  lastUpdatedIso: string,
  now: Date = new Date()
): number {
  const ageHours = (now.getTime() - new Date(lastUpdatedIso).getTime()) / 3.6e6;
  const recency = Math.exp(-ageHours / 24); // decadere ~o zi
  return sourceCount * recency;
}

export function formatSourceCount(n: number): string {
  const de = n >= 20 && n % 100 >= 0 && n % 100 <= 19;
  const noun = n === 1 ? "sursă" : "surse";
  return de ? `${n} de ${noun}` : `${n} ${noun}`;
}
```

```typescript
export interface ClusterMember { source: string; title: string; text: string; }
export interface Summary { title: string; category: string; summary: string; }

const CATEGORIES = ["Politică", "Economie", "Social", "Justiție", "Externe", "Sport", "Cultură", "Altele"];

export async function summarizeCluster(members: ClusterMember[], ai: AiLike): Promise<Summary> {
  const model = members.length >= 2 ? MODELS.large : MODELS.small;
  const sources = members
    .map((m, i) => `[Sursa ${i + 1} — ${m.source}] ${m.title}\n${m.text.slice(0, 4000)}`)
    .join("\n\n---\n\n");
  const prompt =
    `Ești redactor. Pe baza articolelor de mai jos, care relatează același eveniment, ` +
    `scrie un rezumat neutru în limba română, de 2-4 paragrafe, care combină informația ` +
    `din toate sursele fără a copia fraze întregi. Alege un titlu canonic clar și o ` +
    `categorie din: ${CATEGORIES.join(", ")}.\n\n` +
    `Răspunde DOAR cu JSON valid: {"title": "...", "category": "...", "summary": "..."}\n\n` +
    `Articole:\n\n${sources}`;
  const res = await ai.run(model, {
    messages: [{ role: "user", content: prompt }],
    max_tokens: 1500,
    temperature: 0.2,
  });
  const raw = String(res?.response ?? "");
  const jsonStr = raw.slice(raw.indexOf("{"), raw.lastIndexOf("}") + 1);
  const parsed = JSON.parse(jsonStr) as Summary;
  if (!CATEGORIES.includes(parsed.category)) parsed.category = "Altele";
  return parsed;
}
```

```typescript
  },
  async queue(batch: MessageBatch<Job>, env: Env) {
    for (const msg of batch.messages) {
      try {
        await handleJob(msg.body, env);
        msg.ack();
      } catch (e) {
        console.error("job failed", msg.body, e);
        msg.retry();
      }
    }
  },

async function discover(env: Env) {
  const sources = await db.enabledSources(env.DB);
  for (const src of sources) {
    try {
      const res = await fetch(src.feed_url, { headers: { "user-agent": "StiriMD/1.0" } });
      if (!res.ok) continue;
      const items = parseFeed(await res.text());
      for (const item of items) {

        const id = await db.insertArticle(env.DB, {
          sourceId: src.id, url: item.url, title: item.title,
          author: item.author, publishedAt: item.publishedAt, excerpt: item.excerpt,
        });
        await env.QUEUE.send({ type: "fetch", articleId: id });
      }
    } catch (e) {
      console.error("source failed", src.feed_url, e);
    }
  }
}
```

### Task 4.2: Dispecer joburi (fetch → embed → cluster → summarize)

**Files:**
- Modify: `apps/stiri/pipeline/src/worker.ts`

```typescript
async function handleJob(job: Job, env: Env) {
  switch (job.type) {
    case "fetch": return doFetch(job.articleId, env);
    case "embed": return doEmbed(job.articleId, env);
    case "cluster": return doCluster(job.articleId, env);
    case "summarize": return doSummarize(job.clusterId, env);
  }
}

async function doFetch(articleId: number, env: Env) {
  const row = await env.DB.prepare(
    "SELECT url, excerpt FROM articles WHERE id = ?"
  ).bind(articleId).first<{ url: string; excerpt: string | null }>();
  if (!row) return;
  let text = row.excerpt ?? "";
  try {
    const res = await fetch(row.url, { headers: { "user-agent": "StiriMD/1.0" } });
    if (res.ok) {
      const extracted = extractText(await res.text());
      if (extracted.length > text.length) text = extracted;
    }
  } catch (e) { console.error("fetch article failed", row.url, e); }
  await db.setExtracted(env.DB, articleId, text);
  await env.QUEUE.send({ type: "embed", articleId });
}

async function doEmbed(articleId: number, env: Env) {
  const row = await env.DB.prepare(
    "SELECT title, COALESCE(extracted_text, excerpt, '') AS text FROM articles WHERE id = ?"
  ).bind(articleId).first<{ title: string; text: string }>();
  if (!row) return;
  const vector = await embed(`${row.title}\n${row.text.slice(0, 2000)}`, env.AI);
  const vectorId = `a${articleId}`;
  await env.VECTORIZE.upsert([{ id: vectorId, values: vector,
    metadata: { articleId, publishedAt: Date.now() } }]);
  await db.setVector(env.DB, articleId, vectorId);
  await env.QUEUE.send({ type: "cluster", articleId });
}

async function doCluster(articleId: number, env: Env) {
  const row = await env.DB.prepare(
    `SELECT a.title, COALESCE(a.extracted_text, a.excerpt, '') AS text, a.vector_id
     FROM articles a WHERE a.id = ?`
  ).bind(articleId).first<{ title: string; text: string; vector_id: string }>();
  if (!row?.vector_id) return;
  const self = await env.VECTORIZE.getByIds([row.vector_id]);
  const values = self[0]?.values;
  if (!values) return;

  const matches = await env.VECTORIZE.query(values, { topK: 5, returnMetadata: true });
  // primul care nu e articolul insusi
  const candidate = matches.matches.find((m) => m.id !== row.vector_id) ?? null;
  const decision = decideCluster(candidate ? candidate.score : null);

  let clusterId: number | null = null;
  if (decision === "attach" && candidate) {
    clusterId = await clusterIdOfVector(env, candidate.id);
  } else if (decision === "confirm" && candidate) {
    const other = await articleByVector(env, candidate.id);
    if (other && await confirmSameEvent(
      { title: row.title, excerpt: row.text.slice(0, 600) },
      { title: other.title, excerpt: other.text.slice(0, 600) },
      env.AI
    )) {
      clusterId = await clusterIdOfVector(env, candidate.id);
    }
  }
  if (clusterId === null) clusterId = await db.createCluster(env.DB);
  await db.attachToCluster(env.DB, articleId, clusterId);
  await env.QUEUE.send({ type: "summarize", clusterId });
}

async function clusterIdOfVector(env: Env, vectorId: string): Promise<number | null> {
  const row = await env.DB.prepare(
    "SELECT cluster_id FROM articles WHERE vector_id = ?"
  ).bind(vectorId).first<{ cluster_id: number | null }>();
  return row?.cluster_id ?? null;
}

async function articleByVector(env: Env, vectorId: string) {
  return env.DB.prepare(
    "SELECT title, COALESCE(extracted_text, excerpt, '') AS text FROM articles WHERE vector_id = ?"
  ).bind(vectorId).first<{ title: string; text: string }>();
}

async function doSummarize(clusterId: number, env: Env) {
  const members = await db.clusterMembers(env.DB, clusterId);
  if (members.length === 0) return;
  const summary = await summarizeCluster(members, env.AI);
  const score = importanceScore(members.length, new Date().toISOString());
  await db.updateClusterSummary(env.DB, clusterId, {
    title: summary.title, category: summary.category, summary: summary.summary,
    count: members.length, score,
  });
}
```

```typescript
export async function clusterById(db: D1Database, id: number) {
  return db.prepare(
    "SELECT id, canonical_title, category, summary_md, source_count, last_updated_at FROM clusters WHERE id = ?"
  ).bind(id).first();
}

export async function clusterSources(db: D1Database, id: number) {
  const { results } = await db.prepare(
    `SELECT s.name AS source, a.title AS title, a.url AS url, a.published_at AS published_at
     FROM articles a JOIN sources s ON s.id = a.source_id
     WHERE a.cluster_id = ? ORDER BY a.published_at`
  ).bind(id).all();
  return results;
}
```

- **Blocare la fetch articol:** unele site-uri pot bloca boți; fallback pe excerptul RSS e deja prevăzut.
- **Costuri LLM:** confirmarea rulează doar în zona gri; rezumatul doar la schimbarea clusterului. Monitorizează la scară.
- **Fereastra de dedup:** `topK` pe Vectorize nu filtrează pe timp; dacă apar potriviri vechi nedorite, adaugă filtrare pe `publishedAt` din metadata sau un `filter` la query.
